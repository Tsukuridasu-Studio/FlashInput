FAQ

SOUND TOO SIMPLE?

That's the point. But if you're coming from x360ce or a bought-a-cheap-pad forum thread, you probably have questions.

Will I get banned in online games?+
FlashInput contains no DLL injection, no memory reading and no kernel driver — it runs entirely in user space as its own process, the same as any input tool. That's what keeps it invisible to anti-cheat by design. That said, every game's anti-cheat makes its own rules, so no tool can promise a universal guarantee. Use at your own risk.
How is this different from x360ce?+
x360ce works by placing a custom xinput1_3.dll next to each game and tricking the game into loading it. That means per-game setup, version mismatches, and DLLs sitting in folders that anti-cheat scans. FlashInput creates a genuine virtual Xbox 360 controller at the OS level instead — games need zero modification and zero configuration.
Which controllers are supported?+
Any pad built on the DragonRise generic USB chipset — the board inside most budget gamepads, fight sticks and arcade controllers sold without official drivers. If Windows lists it as a "USB Gamepad" or "Generic USB Joystick" under DragonRise, FlashInput will pick it up.
Do I need to install drivers or restart?+
No. FlashInput ships as a single self-contained executable built on .NET 8. Download it, run it once, and it registers its virtual device from user space. Uninstalling is just deleting the file.
Can I remap buttons or adjust sticks?+
v1.0 focuses on a faithful 1:1 translation with deadzone normalization so sticks center properly. Remapping profiles and per-game presets are on the roadmap for v1.1 — watch the releases page.
